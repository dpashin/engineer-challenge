# 8. rate-limiting

Дата: 2026-03-10

## Контекст

Согласно заданию, необходимо реализовать rate limiting для авторизационного флоу.
Необхомо решить, какой алгоритм выбрать.

### Сводное сравнение алгоритмов

```text
Алгоритм	            Точность	Память	    Обработка всплесков (Bursts)	Сложность
Fixed Window	        Низкая	    Очень мало	Плохо	                        Низкая
Sliding Window Log	    Высокая	    Очень много	Хорошо	                        Средняя
Sliding Window Counter	Средняя	    Мало	    Хорошо	                        Средняя
Token Bucket	        Средняя	    Мало	    Отлично	                        Средняя
Leaky Bucket	        Высокая	    Мало	    Запрещены	                    Средняя
```

## Решение

Sliding window log

## Последствия (Consequences)

### Плюсы
- относительная простота реализации
- точность
- обработка всплесков

### Минусы
- память (поскольку делаем демку, можем проигнорировать этот фактор)
