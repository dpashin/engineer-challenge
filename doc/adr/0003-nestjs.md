# 3. nestjs

Дата: 2026-03-10

## Контекст

Нужно выбрать фреймворк для бэка

## Решение

Nest.js

## Последствия (Consequences)

### Плюсы
- Есть большой опыт работы, отсутсвует порог вхождения, можно сразу начать.
- Не нужно переключаться с языка на язык при разработке фронтенд / бэкенд.
- Есть готовые модули для работы с cqrs и graphql

### Минусы
- По сравнению с компилируемыми языками медленнее.
