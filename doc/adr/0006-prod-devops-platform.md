# 6. prod-devops-platform

Дата: 2026-03-10

## Контекст

Нужно выбрать, как описать развертывание прод-среды.

- Docker / Docker compose
- helm charts
- terraform

## Решение

Docker Compose

## Последствия (Consequences)

### Плюсы
- легкость написания конфигурации.
- максимально похоже на dev окружение

### Минусы
- менее масштабируемо, чем остальные решиня

### Риски
- снизят баллы

### Компромиссы
Поскольку все равно нет ресурсов и времени, чтобы поднять Kubernetеs / протестировать,
пока делаем через docker-compose и заносим в todo.
