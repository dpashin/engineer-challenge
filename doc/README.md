# Advanced Engineer Challenge

## Обязательные требования

### Архитектура

Архитектурную схему смотри в [system-context.mmd](system-context.mmd)

#### Компромиссы
1. Postgresql делаем отдельным контейнером, а не master/slave.
Мотивация: Делаем MVP, не хочется тратить время на настройку репликации.

2. Делаем одним контейнером доменную модель, command side и query side.
Мотивация: Для MVP не хочется усложнять межсервисное взаимодействие, по требованиям задачи такой вариант допустим.

#### Стек

##### db

postgresql

Мотивация: imho лучшая opensource db, большой опыт работы.

##### auth-service

Nest.js with graphql module

Мотивация:
- большой опыт работы с Nest.
- не нужно переключаться с языка на язык при разработке фронтенд / бэкенд.

##### frontend

Vue.js

Мотивация:
- не работал с vue раньше, интересно попробовать. 
- Легковесный и более простой, чем решения на базе react или angular. Проще генерировать и ревьюить код.
